Interfaces TypeScript (modelo de datos front-end)

Relaciones: Sale contiene varios SaleItem; cada ítem referencia un Product.

export interface Product {
  id: string;
  sku: string;
  name: string;
  family: "CPU" | "GPU" | "RAM" | "Almacenamiento" | "Mouse" | "Teclado" | "Monitor" | "Laptop";
  price: number;
  stock: number;
  minStock: number;
  status: "Disponible" | "Stock Bajo" | "Sin Stock";
}

export interface Client {
  id: string;
  fullName: string;
  email: string;
  phone: string;
  address: string;
  segment: "VIP" | "Regular";
  totalSpent: number;
  lastPurchaseAt?: string;
}

export interface SaleItem {
  productId: string;
  productName: string;
  sku: string;
  unitPrice: number;
  quantity: number;
  subtotal: number;
}

export interface Sale {
  id: string;
  code: string;
  clientId?: string;
  clientName?: string;
  items: SaleItem[];
  total: number;
  status: "Completado" | "Pendiente" | "Cancelado";
  createdAt: string;
}

export interface DashboardKpis {
  monthlySales: number;
  productsInStock: number;
  activeClients: number;
  ordersToday: number;
}

export interface DashboardData {
  kpis: DashboardKpis;
  monthlySalesChart: { month: string; amount: number }[];
  familyDistribution: { family: string; percentage: number }[];
  lowStockProducts: Product[];
  recentSales: Sale[];
}

Prototipo y componentes

  • Productos: ProductTable, ProductFormModal, StatusBadge, FilterBar
  • Punto de Venta: ProductGrid, CartPanel, CartItem, CheckoutDialog
  • Clientes: ClientList, ClientCard, ClientHistoryDrawer, SegmentFilter

El diseño Figma debe mapear 1:1 con estos nombres de componente para facilitar implementación y revisiones.
